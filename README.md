  <h1>TorqueX – Sports Car Explorer</h1>

  <p>
    TorqueX is a dynamic and visually engaging web application designed to explore and discover world-class sports car brands and their high-performance models through a sleek, modern, and user-friendly interface.
  </p>

  <p>
    The platform provides detailed insights into each vehicle, including specifications, pricing, and images, all fetched dynamically from a public API.
  </p>

  <hr>

  <h2>Features</h2>
  <ul>
    <li>Search cars by name or keyword</li>
    <li>Filter cars based on brand and price range</li>
    <li>Sort cars (price low to high / high to low)</li>
    <li>Add cars to favorites</li>
    <li>Dark/Light mode toggle</li>
    <li>Fully responsive design</li>
  </ul>

  <hr>

  <h2>Technologies Used</h2>
  <ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript (ES6)</li>
    <li>Public API (using fetch)</li>
  </ul>

  <hr>

  <h2>API Integration</h2>
  <p>
    The application uses a public API to fetch real-time sports car data such as car names, images, pricing, and specifications.
  </p>

  <hr>

  <h2>Concepts Used</h2>
  <ul>
    <li>Fetch API for data retrieval</li>
    <li>Array Higher-Order Functions:
      <ul>
        <li>map()</li>
        <li>filter()</li>
        <li>sort()</li>
      </ul>
    </li>
    <li>DOM Manipulation</li>
    <li>Event Handling</li>
    <li>Local Storage (for favorites)</li>
  </ul>

  <hr>

  <h2>How to Run</h2>
  <ol>
    <li>Clone the repository</li>
    <li>Open the project folder</li>
    <li>Run index.html in your browser</li>
  </ol>
